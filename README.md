# Task Tracker

This is a Spring Boot REST API to manage tasks .

## Features

- Create new tasks
- View all tasks
- View task by ID
- Filter tasks by status (e.g., Pending, Completed)
- Update a task
- Delete a task
- Search tasks by title

## Tools Used

- Java 17
- Spring Boot
- Maven
- H2 Database (in-memory)
- Postman (for testing)
